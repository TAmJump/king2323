# §6. NG ワード集(SNS 投稿で絶対に使わない)

これらは法的リスクがあるため、SNS 投稿でも誰かへの返信でも使わない:

| NG ワード | 言い換え |
|---|---|
| 当選 / 当たる | 抽出される / 選ばれる |
| 賞金 | Mission Fund |
| 配当 | (使わない) |
| 投資 | 参加 |
| 倍率 | (使わない) |
| 確率 | (使わない、確率論的表現は禁止) |
| 当選確率 | (使わない) |
| 約束する / 必ず | (使わない、Grant は保証されない) |
| Grant を渡す | Mission Fund で Mission を実行する |

「Grant is not a prize」「Mission Fund executes the Mission」の構文は維持。
